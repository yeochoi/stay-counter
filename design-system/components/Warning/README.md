# Warning

Things to know before booking, like a policy ending or a 183 day limit. One quiet group, not a colored box.

- All warnings on a screen sit together under one coral `secondary` warning icon, one short line each.
- Text in `ink`, the body style, with a relaxed line height.
- A very light `secondary-soft` full width band, edge to edge with no corners. The icon sits in the same 22 column as list markers and the text starts where list text starts.
- No dividers inside. Keep the tint barely visible, a stronger peach looked loud against the cool palette.

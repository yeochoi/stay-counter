# Warning

How the app says something needs checking. Each problem shows once, where it lives.

- A problem with one stay is a small coral icon after that stay's dates in the timeline. No extra line. The stay screen says the reason in a coral box, like This stay is after visa free entry ends on Dec 31, 2026. You need a visa for it.
- A problem with the whole trip, like a tax limit or a single entry visa, is a coral count on Trip details, like 1 to check.
- On the trip overview, one chip under the answer counts the problems, like 2 rules to check. See below. The rules card then puts one `small` line in `coral-text` under each rule it breaks.
- The value in a row keeps its normal style. Only the line under it is coral.
- Calm words. Rules to check, never broken.
- A new trip's plan before saving has no rules card, so its warnings sit in one coral box instead.

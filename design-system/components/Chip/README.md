# Chip

- On `hero`, chips are white at 10 percent with white `small` text, like 147 days, Business, Visa free.
- In content, Now is `primary` with white text, the close to limit chip is `coral-soft` with `coral-text`.
- Every chip uses regular weight. Its fill already makes it stand out.
- Chips never stack into a second line. If they would, drop the least useful one.

# TabBar

Today and Trips, with the add button beside them.

- Phones. A floating glass pill, 16 above the safe area. It floats over content, so it is glass with a shadow, the same as Manna. The selected tab has a filled icon in `primary`, a `small` label in `purple-text` and a `soft` pill at 90 percent behind it. The other is an outline icon in `muted`.
- The add button sits beside the pill at the same height, 62 wide on `primary`. It floats too, so it has a soft shadow, and it never covers a row.
- Laptops. The tabs move to a top bar on `hero`, text only, with Stay Counter in white `title` on the left. The selected tab is white with a `ring` underline.

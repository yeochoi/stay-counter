# GroupedRows

Label and value rows in a white card, for forms, rules and details.

- `surface` card, 1px `line` border, `radius-card`, rows `size-row` tall with a `line` divider.
- Label on the left in `body` `muted`, value on the right in `body` `ink`.
- A `chevron` when the row opens a picker or another step. Read only rows, like Rules for this trip, have no chevron.
- An empty field shows Choose in `muted` regular, never a made up value.
